## What I Learned

### Multiclass Classification

Binary classification predicts one of two classes:

* Yes / No
* Pass / Fail
* Spam / Not Spam

Multiclass classification predicts one class from multiple possible classes.

Examples:

* Cat, Dog, Bird
* Digits (0-9)
* Different types of products

---

### Softmax Function

Softmax converts neural network outputs into probabilities.

Example:

Cat = 0.70

Dog = 0.20

Bird = 0.10

The probabilities always add up to 1 (100%).

The class with the highest probability becomes the final prediction.

---

### Neural Networks with Softmax Output

For multiclass problems:

* Hidden Layers → ReLU
* Output Layer → Softmax

The output layer calculates probabilities for all classes.

---

### Classification with Multiple Outputs

A neural network can predict multiple outputs simultaneously.

Example:

A car image may be classified as:

* Has wheels
* Has doors
* Has headlights

Each output is predicted independently.

---

## Key Takeaways

* Binary Classification = 2 classes
* Multiclass Classification = More than 2 classes
* Softmax converts outputs into probabilities
* All probabilities sum to 1
* Highest probability becomes the prediction
* Softmax is commonly used in image recognition and multiclass tasks
