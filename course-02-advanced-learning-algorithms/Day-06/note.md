## What I Learned

### Why Activation Functions?

Activation functions help neural networks learn complex patterns.

Without activation functions, even a deep neural network would behave like a simple linear model.

---

### Sigmoid Activation Function

The sigmoid function converts any value into a number between 0 and 1.

It is commonly used in binary classification problems where the output represents a probability.

Example:

* 0 = No
* 1 = Yes

---

### ReLU Activation Function

ReLU (Rectified Linear Unit) is one of the most widely used activation functions.

Rule:

* If x < 0 → Output = 0
* If x > 0 → Output = x

Benefits:

* Faster training
* Simpler calculations
* Helps deep neural networks learn efficiently

---

### Choosing Activation Functions

General guidelines:

* Hidden layers → ReLU
* Binary classification output layer → Sigmoid
* Regression output layer → Linear activation

---

## Key Takeaways

* Activation functions make neural networks powerful.
* ReLU is usually the default choice for hidden layers.
* Sigmoid is useful for binary classification outputs.
* Different problems require different activation functions.
