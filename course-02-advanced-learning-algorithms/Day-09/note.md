## Topics Covered

- Deciding What to Try Next
- Evaluating a Model
- Training, Cross-Validation, and Test Sets

## Key Concepts

### Training Set
Used to train the model.

### Cross-Validation Set
Used to select the best model and tune parameters.

### Test Set
Used to estimate the performance of the final model.

## Key Takeaways

- Use diagnostics instead of guessing.
- Evaluate models on unseen data.
- Use training, cross-validation, and test sets properly.
- Cross-validation helps choose the best model.
