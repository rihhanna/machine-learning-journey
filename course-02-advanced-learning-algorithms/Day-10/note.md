## Key Concepts

### High Bias (Underfitting)
Model is too simple and performs poorly.

Solutions:
- More features
- More complex model
- Train longer

### High Variance (Overfitting)
Model performs well on training data but poorly on unseen data.

Solutions:
- More data
- Regularization
- Simpler model

### Learning Curves
Help diagnose whether a model has high bias or high variance.

### Regularization
Prevents overfitting by reducing model complexity.

## Key Takeaways

- High Bias = Underfitting
- High Variance = Overfitting
- Use diagnostics instead of guessing
- Learning curves help understand model behavior
- Regularization helps reduce overfitting
