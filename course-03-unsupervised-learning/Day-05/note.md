# Day 27 — Course 3 | Week 3: State-Action Value Function

## Topics Learned

### State-Action Value Function (Q-Function)

- Learned about the **State-Action Value Function**, also known as the **Q-Function**.
- The Q-function estimates the expected total reward an agent will receive after taking a specific action in a given state and then following the optimal policy.
- It helps the agent decide which action is best in every situation.

---

## Q-Function Definition

The Q-value answers the question:

> "If I take this action in this state, how much total future reward can I expect?"

A higher Q-value indicates a better action.

---

## State-Action Value Function Example

- Explored examples showing how different actions can produce different future rewards.
- Learned how an agent compares Q-values to choose the optimal action.

---

## Bellman Equation

- Learned about the **Bellman Equation**, which defines the relationship between the value of the current state-action pair and the values of future state-action pairs.
- Understood that today's decision depends on both the immediate reward and the estimated future rewards.

The Bellman Equation is the foundation of many reinforcement learning algorithms.

---

## Random (Stochastic) Environment

- Learned that some environments are **stochastic**, meaning the same action may produce different outcomes due to randomness.
- Reinforcement learning algorithms must learn good decisions even when outcomes are uncertain.

## Key Takeaways

- The Q-function measures the quality of taking an action in a specific state.
- Agents choose actions with the highest expected future reward.
- The Bellman Equation allows future rewards to be estimated recursively.
- Reinforcement learning can operate in both deterministic and stochastic environments.
