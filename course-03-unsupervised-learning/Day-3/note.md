## Collaborative Filtering

### What is Collaborative Filtering?
- Recommends items by learning from the preferences of similar users.
- Does not require item descriptions.
- Learns hidden relationships between users and items.

### Making Recommendations
- Predicted ratings for items users have not yet interacted with.
- Learned how recommendation systems estimate user preferences.

### User & Item Feature Vectors
- Learned that:
  - Users are represented by preference vectors.
  - Items are represented by feature vectors.
- Recommendations are generated by comparing these vectors.

### Binary Labels
- Recommendation systems can learn from:
  - Likes 👍
  - Favorites ❤️
  - Clicks 🖱️
  - Purchases 🛒
- Ratings are not always required.

### Mean Normalization
- Learned how subtracting the average rating improves prediction quality.
- Helps recommendation systems perform better for users with limited ratings.

---

## Content-Based Filtering

### Collaborative Filtering vs Content-Based Filtering
- Compared the two recommendation approaches.
- Collaborative Filtering learns from user interactions.
- Content-Based Filtering recommends items based on their characteristics.

### Deep Learning for Content-Based Filtering
- Learned how neural networks can learn richer user and item representations.
- Understood how deep learning improves recommendation quality.

### Recommending from a Large Catalogue
- Learned techniques for efficiently recommending items from millions of available options.
- Understood why scalability is important in production systems.

### Ethical Use of Recommender Systems
- Learned about fairness and responsible AI.
- Understood how recommendation systems can influence user behavior.
- Explored ethical considerations such as:
  - Bias
  - Filter bubbles
  - User privacy
  - Transparency

### TensorFlow Implementation
- Learned how content-based recommendation models are implemented using TensorFlow.
