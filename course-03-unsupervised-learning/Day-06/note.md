## Topics Learned

### Continuous State Spaces

- Learned that many real-world problems have **continuous state spaces**, where states can take infinitely many values instead of a limited set of discrete states.
- Understood why traditional Q-tables are not practical for continuous environments.

## Lunar Lander

- Studied the Lunar Lander example.
- Learned how a reinforcement learning agent controls a spacecraft by balancing fuel usage and landing safely.

---

## Learning the State-Value Function

- Learned the difference between:
  - State-Value Function (V)
  - State-Action Value Function (Q)

- The State-Value Function estimates the expected future reward of being in a state, while the Q-Function evaluates both the state and the action.

---

## Improved Neural Network Architecture

- Learned how deeper neural networks improve reinforcement learning performance.
- Better architectures help approximate value functions more accurately.

---

## ε-Greedy Policy

- Learned about the **ε-Greedy (Epsilon-Greedy) Policy**.
- The agent usually chooses the best-known action but occasionally explores random actions.
- This balances:
  - Exploration
  - Exploitation

---

## Mini-Batch Learning & Soft Updates

- Learned how mini-batch training improves learning stability.
- Understood how soft updates gradually update target networks, making Deep Q-Learning more stable.
