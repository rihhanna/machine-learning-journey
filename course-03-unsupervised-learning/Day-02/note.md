## Collaborative Filtering

### What is Collaborative Filtering?
- Collaborative Filtering recommends items based on the preferences of similar users.
- Instead of relying only on item features, it learns from user-item interactions.
- The idea is:
  - If two users have similar interests, they are likely to enjoy similar items.

### Making Recommendations
- Learned how the algorithm predicts ratings for items that users have not yet rated.
- The model finds hidden relationships between users and items to generate recommendations.

### Using Per-Item Features
- Learned that every item can be represented by a feature vector.
- Each feature describes characteristics of an item.
- The model learns these features automatically during training.

### Collaborative Filtering Algorithm
- Learned that both users and items are represented as vectors.
- Recommendations are generated by comparing user preference vectors with item feature vectors.
- The algorithm minimizes a cost function to learn the best user and item representations.

### Binary Labels
- Learned that recommendation systems do not always use ratings.
- Binary feedback can also be used:
  - Likes 👍
  - Favorites ❤️
  - Clicks 🖱️
  - Purchases 🛒
- These interactions indicate whether a user is interested in an item.

---

## Recommender Systems Implementation

### Mean Normalization
- Learned why mean normalization is important.
- It adjusts ratings by subtracting the average rating of each item.
- This helps the model make better predictions, especially for new users with few or no ratings.
