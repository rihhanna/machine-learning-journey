# Day 26 — Course 3 | Week 3: Reinforcement Learning (Part 1)

## Topics Learned

### Introduction to Reinforcement Learning
- Learned that Reinforcement Learning (RL) is a type of machine learning where an agent learns by interacting with an environment.
- Instead of learning from labeled data, the agent learns through trial and error by receiving rewards or penalties.

---

## Key Concepts

### Agent
- The learner or decision-maker.
- Takes actions to achieve a goal.

### Environment
- Everything the agent interacts with.
- Responds to the agent's actions and provides feedback.

### State
- Represents the current situation of the agent within the environment.

### Action
- A decision or move made by the agent.

### Reward
- Feedback received after taking an action.
- Positive rewards encourage good actions, while negative rewards discourage poor actions.

### Policy
- A strategy that tells the agent which action to take in each state.
- The goal is to learn the best policy that maximizes long-term rewards.

---

## Mars Rover Example

- Learned how reinforcement learning can be applied to a Mars rover.
- The rover learns to choose actions that maximize its chances of successfully completing its mission while avoiding dangerous situations.

---

## Return

- Learned that the **Return (G)** is the total future reward an agent expects to receive.
- Future rewards are discounted using a **discount factor (γ)**.
- This encourages the agent to balance immediate and future rewards.

---

## Reinforcement Learning Workflow

1. Observe the current state.
2. Choose an action based on the policy.
3. Receive a reward.
4. Move to a new state.
5. Repeat the process to improve the policy.

## Key Takeaways

- Reinforcement Learning learns through interaction with an environment.
- The agent improves by maximizing cumulative rewards.
- Policies determine the agent's decisions.
- Returns measure the total expected reward.
- Discount factors help balance short-term and long-term rewards.
